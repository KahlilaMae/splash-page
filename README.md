# Kahlila Mae Liverpool - Splash Page

A professional splash page for Kahlila Mae Liverpool, exploring the intersection of Learning & Development, Leadership, Learning Design, and AI + Learning.

## Features

✨ **Modern Design** - Clean, professional layout with gradient styling  
📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile  
🔗 **LinkedIn Integration** - Direct link to LinkedIn profile  
⚡ **Fast Loading** - Lightweight and optimized  
🎨 **Beautiful Animations** - Smooth fade-in and hover effects  

## How to Use

1. **View the page**: Open `index.html` in your browser
2. **Customize**: Edit the LinkedIn URL in `index.html` to your profile
3. **Deploy**: Use GitHub Pages to host for free

## GitHub Pages Setup

1. Go to your repository settings
2. Scroll to "Pages" section
3. Select "main" branch as the source
4. Your page will be live at: `https://yourusername.github.io/splash-page`

## Customization

### Change Colors
Edit the gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Update LinkedIn URL
In `index.html`, replace the href:
```html
<a href="https://www.linkedin.com/in/your-profile/" target="_blank">
```

### Modify Content
Edit the name and tagline directly in `index.html`
